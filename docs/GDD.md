# «ДАВКА ДО РАБОТЫ» — диздок (GDD) v1
Telegram Mini App · горизонтальная ориентация · пиксельный beat'em-up · пародийное метро
Сестра «ШМЯКОДРОМА»: тот же уровень полировки, «конфетка», всрато-смешно, но красиво.

> Юмористический вымышленный проект. Не связан с официальным метрополитеном и транспортными органами. Никаких официальных логотипов, буквы «М», реальной схемы, фирменных шрифтов и цветов линий 1-в-1, брендов. Никакой политики. Названия станций — только пародийные из списка Сергея.

---
## 0. Питч
Ты опаздываешь на работу. Между тобой и офисом — всё «Неофициальное Смешное Метро»: толпы, баулы, «Можно пройти?», турникеты-мутанты и боссы на конечных. Драка вбок (side-scroller beat'em-up) короткими сценами по 60–120 c, одна станция = один уровень. Плюс отдельный режим «Пробиться к выходу» (30–60 c) и Телеграм-соревнование с друзьями.

Принципы: 1) управление одной рукой на каждую сторону, 3 кнопки максимум; 2) поле игры — 100% экрана, HUD тонкий по краям; 3) текст только чёткий, крупный; 4) каждый удар — сочный (тряска, частицы, звук, вибро); 5) никаких повторов: у каждого врага, босса, мира — своя фишка.

## 1. Core loop и управление
### 1.1 Петля
Станция (уровень) → 3–5 «вагонных сцен» (арена-стопов: экран блокируется, волна врагов, «Осторожно, двери закрываются» — двигаемся дальше) → финальная сцена станции → оценка (★1–3) → жетоны → следующая станция. Конечная = босс. Мета: домик «Бытовка», скины, коллекция, квесты.

### 1.2 Управление (ландшафт)
- **Левая половина экрана — плавающий стик.** Где коснулся, там центр (никакой фиксированной мелкой кнопки). Радиус 56 CSS px, рисуется полупрозрачно (35%) только пока палец на экране.
- **Правая половина — жесты, без кнопок:**
  - тап = удар (серия 1-2-3 тапами);
  - свайп вверх = прыжок; свайп вверх при касании врага = апперкот;
  - свайп вниз = подкат/присед;
  - свайп вперёд = рывок-толчок («локоть»);
  - удержание 0,4 c = заряд суперудара (кольцо вокруг героя), отпустил — удар оружием;
  - тап по лежащему предмету — подобрать (автоподбор, если стоишь на нём и тапнул).
- **Единственная видимая кнопка:** «СУПЕР» (кружок 64×64 CSS px, правый нижний угол в safe-area, вне игрового поля при широком экране либо поверх с 80% прозрачностью), загорается, когда шкала «Злость пассажира» полна.
- Пауза — кнопка 44×44 в левом верхнем углу (зоне вне поля, внутри safe-area).
- Опция «Кнопочный режим» в настройках для тех, кто не любит жесты: 3 кнопки по 72 px (Удар / Прыжок / Супер).
- Ассист: автонаведение удара на ближайшего врага по горизонтали ±12 px по Y (бит-эм-ап на «глубине» 2.5D — частая боль, снимаем её).
- Буфер ввода 120 мс, «coyote» прыжка 80 мс, отмена анимации удара в рывок после кадра 3.

### 1.3 HUD (минимум)
- Сверху тонкая полоса 14 px (внутренних): слева сердечки-жетоны HP (не полоса), в центре «бегущая строка» табло станции (название + следующая), справа таймер/очки.
- Шкала Злости — дуга вокруг кнопки «СУПЕР», а не отдельная полоса.
- HP врагов — только у босса (сверху), у обычных — визуально (красное лицо, пот, рваная одежда).
- Весь текст — на отдельном overlay-канвасе в реальном devicePixelRatio, минимум 12 CSS px, пиксельный шрифт с целыми масштабами. Никакой мыльной мелочи.

## 4. Боссы (по одному на конечной каждой ветки)
Каждый — арена в вагоне/на платформе, 3 фазы, своя механика, телеграфы крупные.

1. **Бабушка-танк** (Компотная линия, «Компотнарка») — тачка-баул, таранит; фаза 2 — достаёт банки с огурцами (бомбы); фаза 3 — «А МЕСТО?!» кричит, экран дрожит, надо прятаться за поручни. Слабость: стукнуть по тачке, когда она застряла в двери.
2. **Турникет-мутант «Тренер Турникет»** («Алма-Вафлинская») — железные «руки»-створки хлопают по таймингу; проходить надо в ритм зелёной стрелки; фаза 3 — плюётся проездными.
3. **Контролёр Апокалипсиса** («Щёлкокошская») — компостирует игрока (стан); вызывает стажёров; фаза 3 — огромный жетон-штраф катится по арене.
4. **Машинист-демон** («Новокиселевая») — бой на крыше/в кабине: вагон тормозит → инерция всех сносит вперёд; читать сигналы светофора, чтобы держаться.
5. **Эскалатор-Пожиратель** («Котлетники») — ступени-зубы, бег вверх по эскалатору вниз (вечный бег), уворачиваться от чемоданов, бить «кнопку стоп» в 3 местах.
6. **Король Баулов** («Аэроторт Плюшково») — пирамида из баулов, каждый удар сбивает баул и из него вылезает враг; финал — король голый в трусах-тельняшке бежит (смешная погоня).
7. **Голубиный Генерал** («Бульвар Дмитрия Понского») — стая голубей, команда «ПИКИРУЙ», крошки-приманки как оружие игрока.
8. **Уличный Рок-Оркестр** («Зяблево») — ритм-босс: атаки в такт музыки, удары по нотам дают x2.
9. **Королева Очереди** (кольцо, «Марьина Окрошка») — бесконечная очередь клонов; надо найти «первого» в очереди (подсказка — шапочка).
10. **ДЕДЛАЙН** (финал, Кольцевая, «Новосдобная») — гигантские часы-офис: стрелки бьют, начальник кидает «почему опоздал?» пузыри-тексты; финальная фаза — бег к офисной двери в 9:00:59.

| 8 | **Бублинская** (по Люблинско-Дмитровской) | салатовый | музыкальные переходы, граффити-без-слов | шумовые волны | ритм: бонус за удары в бит | Физкекс → Селёдерская → Обжорная → Достоплюшская → Трубочная → Рисотская → Бублино → **Зяблево** (Уличный Рок-Оркестр) |

Полная карта всех 15 веток с переименованиями — в Приложениях А и Б. Станции вне кампании используются в «Пробиться к выходу», ежедневном маршруте и бонусных ветках. Бонусные мини-ветки (обновления): Кекская (Некрасовская), Филейная (Филёвская), Бисквитская (Бутовская), Обжорное кольцо (МЦК) — наземная, драки на ходу с видами на город, Новоморковская (Троицкая).

Структура уровня: платформа → вагон → переход/эскалатор → платформа. Названия станций на табло и на «стене» станции (пиксельная плитка). Голос диктора объявляет каждую.

Особые уровни: **«Эскалатор-ран»** (один в каждом 2-м мире): автобег вверх по эскалатору, который едет вниз; уклон от чемоданов, тележек, катящихся апельсинов; переход по поручню = бонус.

## 6. Оружие, пикапы, усиления
Подобранное оружие — 5–12 ударов, потом ломается смешно.

| Оружие | Удар | Особое | Как ломается |
|---|---|---|---|
| **Рюкзак-таран** | широкий разворот | сносит 3 врагов сразу | рвётся — вываливаются конспекты |
| **Мокрый зонт** | тычок | раскрыть (удержание) = щит + брызги | выворачивается ветром |
| **Кофе-плевок** (стакан) | дальний плевок | лужа — скользь | пустой стакан бросить |

## 7. Комбо
- Счётчик ударов без получения урона: 10/25/50/100 → «НЕПЛОХО», «ДАВКА!», «ЗАКРЫВАЙ ДВЕРИ!», «КОНЕЧНАЯ!!!» (огромный пиксельный текст, хитстоп 80 мс).
- Множитель очков ×1…×4.
- Именные комбо (раскрываются в «Справочнике»):
  - **«Локоть → рюкзак → двери»**: последний удар толкает врага в закрывающиеся двери — его увозит поезд на перрон (+500).
  - **«Кегли»**: бросок врага сбивает 3+ — страйк, звук кеглей.
  - **«Эскалаторный пинг-понг»**: враг катится вниз и возвращается.
  - **«Кофейный каток»**: лужа + подкат = враги скользят цепочкой.
  - **«Вежливый»**: ответить «Да» троим «Можно пройти?» подряд.
  - **«Жонглёр»**: держать врага в воздухе 5 ударов.
  - **«Бабкин гнев»** (только Зинаида): клюка-подтяг + супер.
- Злость копится от ударов и от полученного урона (камбэк-механика).

## 8. Режимы
1. **Кампания «Опоздание»** — 10 веток × 8 = 80 уровней, звёзды: пройти / без смерти / по времени-очкам.
2. **«Пробиться к выходу»** (30–60 c) — вагон в разрезе забит, ты в середине, двери откроются на «твоей» станции через N секунд. Толкай, ныряй под руки, переползай через сумки. Таймер «Осторожно, двери закрываются» с последними 3 секундами (замедление, драм-звук). Процедурная расстановка из 40 шаблонов + модификаторы (лето/потные, ночь, футбол, Новый год). Цепочка станций — сколько вышел подряд. Мгновенный рестарт тапом.
3. **Ежедневный маршрут** — один на всех (сид по дате, UTC+3): 3 станции подряд из случайных веток + модификатор. Одна попытка «в зачёт», остальные тренировочные. Таблица по чату/друзьям.
4. **Призрак друга** — в Выходе и Маршруте поверх летит полупрозрачный силуэт друга (запись ввода).
5. **Эскалатор-бесконечность** (открыть после мира 5) — бесконечный бег.
6. **Хаос-час** (после финала) — случайные модификаторы каждые 15 c: все враги бабки, низкая гравитация, все — голуби, зеркальный экран.
7. **Босс-раш** — все боссы подряд.

## 9. Мета
- **Валюты:** жетоны (обычная, с уровней), «золотые проездные» (редкая: боссы, квесты, ачивки). Никакого доната в MVP. Возможно позже Telegram Stars — только косметика.
- **Прогрессия:** звёзды открывают ветки (ветка N требует 2N·… ⭐, мягко), героев.
- **Прокачка (лёгкая):** у каждого героя 3 перка (HP+, Злость быстрее, оружие крепче) по 3 уровня. Без гринда.
- **Скины (по 4 на героя):** Серёга-пижама, Серёга-кибер, Бабка-рокерша, Бабка-ниндзя, Курьер-дед-мороз, Варя-готка, Гена-балерина, Метрофан-шлем, Шмякс-гибрид… + шапки (как в ШМЯКОДРОМЕ) и «следы» (следы шагов: лужи, конфетти, искры).

- **Коллекция «Бюро находок»**: 80 потерянных вещей, каждая со смешной биркой-текстом.
- **Справочник пассажира** (бестиарий): карточки врагов/боссов, смешная биография, «как победить».
- **Ежедневные квесты:** 3 в день из 24 типов, например: «Отправь 5 врагов в двери», «Пройди станцию только зонтом», «Ответь „Да“ 3 вежливым», «Выход на 3 станции подряд», «Не тронь маму с коляской», «Комбо 50 Бабкой». Награда: жетоны/проездной; серия 7 дней — скин.
- **Ачивки (40+)**: «Ехал стоя», «Уступил место бабке», «Не заплатил за проезд» (прыгнул через турникет), «Плюшкин», «Вежливость — сила», «Кольцевик» (круг без смерти), «Голубятник», «Проспал станцию», «Двери закрываются — я в вагоне», «Пассажир года».

## 10. Телеграм-фишки
- **Хаптики** (`HapticFeedback`): лёгкий удар — `impactOccurred('light')`, тяжёлый/бросок — `medium`, супер/босс — `heavy`, двери закрылись — `notificationOccurred('warning')`, победа — `success`. Свой «узор» у каждого героя. Выключатель в настройках.
- **Лидерборд:** по чату (если запущено из группы через startapp-параметр) и по друзьям; сохранение рекорда и ежедневного маршрута на бэке (простой сервер: /score, /daily, /ghost; проверка `initData` подписью бота).
- **Призраки:** запись ввода (детерминированная физика, фиксированный шаг 1/60, сид), ~2–6 КБ, хранить на сервере, ссылка `t.me/<бот>?startapp=ghost_<id>`.
- **Вызов другу:** «Побей мой результат на Омлетном Ряду» — ссылка с сидом.
- `CloudStorage` для сейва (дубль в localStorage), `BackButton` = пауза/назад, `setHeaderColor`/`setBackgroundColor` под ветку, `disableVerticalSwipes()` чтобы свайпы не сворачивали апп, `requestFullscreen()` + `lockOrientation()` (где поддерживается).

## 11. Сочность (juice), гэги, аудио

- Хитстоп 40–100 мс по силе удара, тряска экрана 1–4 px (целые пиксели), «вспышка белым» врага 1 кадр.

- Звукоподражания-плашки: «ХРЯСЬ», «БАМС», «ШМЯК» (отсылка), «ПЫЩ», «ОЙ».
- KO-гэги (у каждого врага свой, см. §3) + общий: враг улетает на рельсы и его «увозит» поезд с «ту-ту».
- Двери вагона закрываются с зажатым врагом — он едет с торчащей ногой.

**Диктор (озвучка или синтез + субтитры):**
«Осторожно, двери закрываются. Следующая станция — Омлетный Ряд», «Уважаемые пассажиры, при выходе не забывайте свои баулы», «Поезд дальше не идёт, просьба побить босса», «Станция Новосдобная. Переход на работу. Вы опоздали». Голос — нейтральный, без копирования реальных дикторов; пародийный «голос робота».

**Аудио:** чиптюн 8-бит. Тема на мир (10), босс-тема (2 варианта), меню, Выход-тема (ускоряется к концу). SFX: 60+ (удары по типу, двери, гудок, турникет, стук колёс, эскалатор, писки). Колёса «тук-тук» в ритме музыки. Сжатие ogg/mp3, суммарно ≤ 4 МБ, ленивая загрузка по мирам.

## 13. Арт-дирекшн
- **Внутреннее разрешение:** 384×216 (16:9), целочисленный апскейл (×3 на 1152×648, ×4, ×5…), `imageSmoothingEnabled=false`. Для широких экранов (19.5:9) — расширяем видимую область по X до 468×216 (больше фона, не меньше героя). Поле игры не сжимается UI.
- **Палитра:** 48 цветов, основа — тёплая «компотная» (вишня, сливочный, мятный, горчичный, шоколад), у каждого мира 6 акцентных. Тени — цветные (фиолетовые), не чёрные. Контур 1 px тёмный цветной (не чистый чёрный).
- **Спрайты:** герои 48×64, обычные враги 32–48×48–72, боссы 96–160×96–128, пикапы 16×16, частицы 2–6 px.
- **Кадры анимации:** idle 6, ходьба 8, бег 8, удар1/2/3 по 4/4/6, прыжок 4, воздушный удар 4, подкат 4, захват 3, бросок 5, получение урона 3, KO 8, подъём 6, супер 12, победная поза 8. Враги: idle 4, ходьба 6, атака 5, урон 2, KO 6–8. Боссы ~60 кадров каждый. 12 fps для анимаций, 60 fps для движения.
- **Фон:** 3 параллакс-слоя (туннель/стена, колонны, передний план с поручнями), анимированные лампы, поезд проходит фоном.
- **Всратость контролируемая:** смешные лица, утрированные пропорции, но чистый пиксель и читаемые силуэты (как в ШМЯКОДРОМЕ — красиво, не дёшево).
- **UI-шрифт:** пиксельный кириллический (например, собственный 8×8/8×12 или открытый шрифт с OFL, проверить кириллицу), отрисовка на overlay-канвасе в devicePixelRatio, кратные масштабы, минимум 12 CSS px, обводка 1 px для читаемости.
- **Лэйаут ландшафта:** safe-areas (`env(safe-area-inset-*)` + Telegram `safeAreaInset`/`contentSafeAreaInset`): кнопки и HUD внутри, «чёлка» — только фон. Кнопки ≥ 44×44 CSS px, «СУПЕР» 64. Если поле меньше экрана — поля-«рамки» в стиле плитки станции, туда идут кнопки.

## 14. Техника
- HTML5 Canvas + vanilla JS (как ШМЯКОДРОМ), без тяжёлых движков. Два канваса: игровой (пиксельный) и overlay (текст/UI, devicePixelRatio).
- Фиксированный шаг логики 1/60 c (аккумулятор), детерминированный RNG (сид) — для призраков.
- Спрайт-атласы PNG, ≤ 2048², загрузка по мирам; общий вес MVP ≤ 8 МБ.
- **Полноэкранный ландшафт в Telegram (обязательно, фикс из ШМЯКОДРОМА, не откатывать):**
  1. `tgInit()`: `ready()`, `expand()`, затем `requestFullscreen()` если `isVersionAtLeast('8.0')`; `lockOrientation()` если есть; `disableVerticalSwipes()` (7.7+); цвета хедера/фона.
  2. Высота = max(window.innerHeight, tg.viewportHeight, tg.viewportStableHeight), нули/undefined игнорировать. Никогда только viewportStableHeight.
  3. `resize()` запоминает последние w×h@dpr; не изменились — `return false`, иначе пересчёт и `return true`.
  4. Пересчёт на `viewportChanged`, `fullscreenChanged`, `safeAreaChanged`, `contentSafeAreaChanged`, `window.resize`, `orientationchange` и таймерах 50/300/800 мс. Не один resize() сразу после expand(). Изменился размер в меню — перестроить меню.
  5. Safe areas: inset = max(CSS `env(safe-area-inset-*)`, `tg.safeAreaInset` + `tg.contentSafeAreaInset`). Фон на весь экран, кнопки/HUD только внутри inset.
  6. Портрет: пауза и пиксельный экран «Поверни телефон» с вращающимся вагоном; в ландшафте — автопродолжение.
- **Ландшафт:** `Telegram.WebApp.lockOrientation()` (Bot API 8.0+, если есть), `requestFullscreen()`; если телефон в портрете — пауза + пиксельный экран «Поверни телефон» с анимацией вращающегося вагона; игра не стартует в портрете. На десктопе — окно 16:9.
- Ввод: Pointer Events, multi-touch (стик + жесты одновременно), `touch-action:none`, `disableVerticalSwipes()`.
- Сейв: localStorage + CloudStorage, версия схемы и миграции (урок ШМЯКОДРОМА со звёздами).
- Производительность: 60 fps на средних Android, пул объектов для частиц, ≤ 40 врагов на экране (толпа-волна — один спрайт).
- Бэк (позже MVP+): Node/Python, проверка initData, лидерборды, призраки, ежедневный сид.
- Тесты: автобот-проходчик уровней (AI-скрипт, проверяет проходимость и время), снапшоты рендера, проверка лэйаута на 10 разрешениях.

## 16. MVP и обновления
